# Происхождение

Провайдер написан с нуля против публичного API **linq2db** и против публичного API движка
**H2Sharp**. Кода linq2db и кода движка здесь нет: берётся только API.

| | |
|---|---|
| linq2db | <https://github.com/linq2db/linq2db>, версия **6.5.0** (релиз с nuget.org) |
| Движок | <https://github.com/dimzon/h2sharp>, порт **H2 2.5** |
| Ориентир по поведению | замороженный снимок документации H2 в `../h2sharp/docs/` и эталонный jar `h2-2.5.259-SNAPSHOT.jar` на JVM |

Сборка идёт против **релизного пакета** `linq2db` с nuget.org, а не против исходников
linq2db: исходники нужны были только для чтения API.

## Чего в провайдере нет

Ничего от PostgreSQL: провайдер писался под H2, а не переносился. Диалект, типы, функции и
идентификаторы — H2-овские, и они сверяются с документацией и с эталонным jar'ом.
